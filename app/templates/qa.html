Academic Architecture: Extractive Question Answering

Extractive Question Answering locates the exact text span within a reference context that answers a natural language question. Unlike generative models, extractive QA does not hallucinate new facts, guaranteeing that every answer is strictly backed by verifiable evidence.

Execution Pipeline:
Evidence Context → Sentence Segmentation → TF-IDF Similarity Ranking → Entity Category Match → Exact Answer Span Extraction
